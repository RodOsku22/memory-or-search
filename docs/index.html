Memory or Search? Where AI brand recommendations come from

A pilot on Petra Labs’ four product categories: 907 answers from ChatGPT, Claude and Gemini with web search turned off and on, to separate what a model already remembers about a brand from what it finds when it searches.

Rod Oskouian · November 9, 2026 · 907 answers · 15–30 runs per cell

Motivations

Petra Labs’ research keeps pointing at a layer it has not measured. The cross-engine study says it cannot tell whether a recommended brand comes from retrieved pages or from “parametric memory,” and calls that distinction central for GEO. How Are SEO and AEO Different? argues that models form a prior sense of a brand from training data, and that this prior can be influenced over time. The deleted-page study deliberately used pages newer than the training cutoff to rule memory out.

The cheapest way I could find to look at that layer is to ask the same question twice: once with web search off, so the model can only use what it learned in training, and once with search on. I built the harness, ran it and wrote this analysis by leveraging Claude Code. The sample sizes are small, so treat everything here as directional. The method is the point: it is cheap, repeatable, and it uses the prompts, brand lists and noise-floor approach Petra Labs has already published.

Key Takeaways

Glossary

Memory
What the model says with web search turned off. It can only draw on what it learned in training.
Search
The same model and prompt with web search turned on, so live pages can add to or override memory.
Visibility
Share of answering runs that name a brand. An answering run names at least one brand from the category's list.
Search lift
Search visibility minus memory visibility, in percentage points.
Movable share
Of a brand's visibility with search on, the part that memory alone does not produce: max(0, search − memory) ÷ search. A rough gauge of how much visibility depends on what is on the web right now.
TVD
Total variation distance between two brand profiles: the share of recommendation weight that would have to move to turn one into the other. 0 is identical, 1 is no overlap.
Noise floor
The 95th percentile of TVD when memory and search labels are shuffled at random. Movement above it is unlikely to be run-to-run chance.

Results

1. Search always changes the answer, but by very different amounts per engine

In all 16 cells (4 categories × 2 prompts × 2 engines), the distance between the memory and search brand profiles cleared its permutation noise floor. The size of the change depends mostly on the engine. ChatGPT’s search-on answers stay close to its memory: mean TVD 0.21 against a floor of about 0.13, and a mean rank correlation of 0.86. On secured credit cards its two profiles are barely distinguishable (TVD 0.10 against a floor of 0.09). Claude moves much further: mean TVD 0.35 and rank correlation 0.63.

At the brand level, 41 Claude brand-cells shifted significantly (Benjamini–Hochberg q ≤ 0.05), against 12 for ChatGPT. Part of that gap is sample size, since ChatGPT cells have 15 runs and Claude cells about 25–30. Among brands that are strong in at least one condition, the average movable share is 29% on Claude and 14% on ChatGPT.

2. What changes when search is on

  • Search adds challengers the model does not remember. For “Recommend meal kit delivery services,” Claude never named Hungryroot or Tovala from memory. With search on it named Hungryroot in every answer and Tovala in 68%. On secured cards, DCU went from 0% to 82% and Bank of America from 20% to 91%.
  • Search drops brands the model does remember. Sunbasket appeared in every Claude memory answer about meal kits and in 14% after search.
  • Search localizes. From memory, ChatGPT’s crypto list is global and includes DeFi: OKX (87%), Bybit, Uniswap and PancakeSwap (73% each). With search on it frames the answer “for U.S. users,” and those four fall to 0–13%.
  • A mention is not a recommendation. Asked about crypto exchanges for a New Yorker, Claude with search named Crypto.com and Binance in 92% of answers, largely to say they are not available in New York under the BitLicense. Counting mentions, as this pilot and most visibility tools do, scores that as visibility.

3. On broad prompts, the engines’ memories agree more than their searches do

Petra Labs found that most brands swing widely across engines with search on. Comparing the same two engines in both conditions, the average cross-engine range on broad prompts was 9–16 points from memory and 23–36 points with search, in meal kits, crypto and live sports. In those three categories, much of the disagreement appears when search is turned on. Secured cards run the other way: the memories disagree (42 points) and search narrows the gap (27). On situational prompts, search narrowed disagreement in three of four categories. Adding Gemini’s memory-only answers raises the memory ranges to 21–27 points on broad prompts, still at or below the two-engine search ranges, though a three-engine range is not strictly comparable with a two-engine one.

4. One hypothesis did not hold

I expected search to matter more for specific, situational questions than for broad ones, since added buyer context reshuffles citations heavily in Petra’s Prompt Radius study. In this pilot it did not: mean TVD was 0.27 for broad prompts and 0.29 for situational ones, with no consistent pattern by category. The engine mattered far more than the prompt type.

What this means for spend and attribution

  • Measure movability before promising movement. A brand that is anchored in an engine’s memory will show little change from content work on that engine between model releases, so a visibility jump there is more likely a model update than an intervention. A pre-engagement memory-vs-search scan would tell a client which engines and prompts their spend can actually move, and help attribution separate intervention effects from model effects.
  • Plan by engine, not just by category. In this pilot ChatGPT’s search-on answers mostly confirmed what it already believed, while Claude’s followed what it read. If that holds at scale, fresh earned and owned content pays back faster on Claude-like engines, and ChatGPT’s head terms need the slower work of shifting the prior.
  • Track whether a mention is positive. In regulated categories, search-on answers name brands in order to rule them out. For a client like a sports prediction market, where availability differs by state, a mention-count dashboard can read exclusion as visibility.
  • The live web decides eligibility. Search turned ChatGPT’s global crypto list into a U.S.-compliant one. For categories where rules change faster than training data, the retrieval layer is where a brand’s current status gets fixed.

Experiment Setup

  • Collected: November 9, 2026, 11:15–11:40 pm ET, one session.
  • Engines (API): OpenAI gpt-5.5 via the Responses API with reasoning off, the closest API match to ChatGPT “Instant”; Anthropic claude-sonnet-5 via the Messages API; Google gemini-3.5-flash-lite, memory only.
  • Conditions: memory = no tools; search = provider web search on. ChatGPT search was forced on every call with search context set to low; Claude could run up to three searches and searched in every search-on call.
  • Prompts: Petra Labs’ four broad prompts from the cross-engine study (“Recommend secured credit cards.” and so on), plus one situational version of each that adds buyer context. No system prompt, no conversation history.
  • Runs: 15 per cell for ChatGPT (budget), up to 30 for Claude (credit ran out after about 90% of calls, leaving 18–30 answering runs per cell), 30 for Gemini memory. 907 answers in total.
  • Extraction: whole-word matching against Petra Labs’ published brand lists plus aliases, with five brands added after a review of answers (Uniswap, PancakeSwap, Freshly, CHSN, NBC Sports Chicago). Following Petra, EveryPlate and Factor count as HelloFresh. Matches were spot-checked by hand.
  • Statistics: visibility as a share of answering runs; bootstrap 95% intervals and permutation tests for each brand’s lift, Benjamini–Hochberg corrected within each engine and prompt; TVD between brand profiles against a 1,000-shuffle permutation noise floor, as in Petra’s sampling-noise and Prompt Radius work.

Limitations

  • Small samples. By Petra’s own noise analysis, 15 runs can only reliably detect large shifts, roughly 35 points for a brand near 50% visibility. Brand-level ChatGPT results are the least certain here.
  • API, not the consumer apps. Petra’s access-surface study shows the API behaves differently from logged-in and logged-out ChatGPT. The memory-vs-search comparison is within one surface, so it holds as a contrast, but the levels will not match what consumers see.
  • “Memory” is approximate. Search-off answers reflect training data plus each provider’s default behavior without tools. Cost settings (reasoning off and low search context for ChatGPT, a three-search cap for Claude) may also shape the search-on answers.
  • Mentions, not sentiment. A brand counts as visible whenever it is named, including as something to avoid.
  • One evening, two search engines. Gemini’s free tier allows no search calls, so Gemini appears only on the memory side. All runs come from a single session.

Future Work

  • Scale to 100+ runs per cell and add Gemini and AI Overviews with search, so the cross-engine result covers Petra’s five engines.
  • Run the same panel on logged-out ChatGPT, where consumer behavior lives.
  • Classify each mention as a recommendation, a neutral mention or an exclusion before counting it.
  • Re-run across a model release to watch the memory layer itself move, and test whether a placement campaign shifts it.
  • Apply the scan to a fast-changing regulated category such as sports prediction markets, where a model’s training data predates a brand’s current legal status.
