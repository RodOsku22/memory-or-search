Key Takeaways

Glossary

Memory
What the model says with web search turned off. It can only draw on what it learned in training.
Search
The same model and prompt with web search turned on, so live pages can add to or override memory.
Visibility
Share of answering runs that name a brand. An answering run names at least one brand from the category's list.
Search lift
Search visibility minus memory visibility, in percentage points.
Movable share
Of a brand's visibility with search on, the part that memory alone does not produce: max(0, search − memory) ÷ search. A rough gauge of how much visibility depends on what is on the web right now.
TVD
Total variation distance between two brand profiles: the share of recommendation weight that would have to move to turn one into the other. 0 is identical, 1 is no overlap.
Noise floor
The 95th percentile of TVD when memory and search labels are shuffled at random. Movement above it is unlikely to be run-to-run chance.

Layer Lens

Pick a category and brand to see, per engine and prompt, how much of its visibility comes from memory and how much depends on search. Search-dependent visibility is the part that content and placements can move between model releases.

Bucket thresholds: strong means visible in at least 50% of answering runs. Anchored = strong in both; Search-dependent = strong only with search; Displaced = strong only from memory; Peripheral = strong in neither. Lift intervals are bootstrap 95% CIs; "significant" means Benjamini–Hochberg q ≤ 0.05 within the engine and prompt.
